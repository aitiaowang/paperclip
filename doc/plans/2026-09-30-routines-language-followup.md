# 定时任务全局语言适配补漏

用户截图中的定时任务页面只有导航和面包屑跟随语言设置，正文仍为硬编码英文。本轮沿用现有 i18next 和组织菜单语言入口，补齐定时任务模块；不引入新的语言设置。

## 实施范围

- 主列表与旧版列表：标题、说明、空状态、分组排序、创建弹窗、执行策略、文件夹操作及提示消息。
- 详情与旧版详情：概览、导航、保存及冲突提示、触发条件卡片、运行结果和时间显示。
- 调度与触发器：时间计划、cron 可读说明、完整触发器向导、Webhook 配置、运行变量与变量编辑。
- 运行与历史：列表行、审计活动、版本比较及恢复弹窗。
- 共享文件夹控件的通用文案接入语言资源。
- 富文本编辑器的辅助标签实时切换：通过 MDXEditor 公开 realm 插件更新翻译，保留原编辑器实例、草稿和撤销历史。

所有 API 枚举、cron 表达式、用户标题、任务内容、文件夹名称及原始诊断信息保留原值。切换语言不会重新初始化任务草稿或调度设置。派生分组、面包屑与历史比较的缓存包含语言依赖。

## 验证

- 新增列表回归测试先复现中文下仍出现英文正文的失败；修复后主列表和旧版列表均验证中英双向切换及标题草稿保留。
- 列表、文件夹和词条校验：3 文件、35 项通过。
- 列表行、运行与历史：5 文件、26 项通过。
- 详情组件与辅助函数：6 文件、24 项通过。
- 调度、运行变量、触发器向导、cron 与词条校验：6 文件、35 项通过（词条校验与上面一组重复，不作独立总数累加）。
- 编辑器：2 文件、49 项通过；真实编辑器回归先复现辅助标签不随语言切换，再验证双向切换、同一编辑器实例与未提交内容保留。
- UI 类型检查、生产构建、差异空白检查通过。构建保留项目既有 Vite/CSS/包体积提示。
- 浏览器验证：中文定时任务页、创建弹窗与高级策略说明；另一标签页切换全局语言后，打开的弹窗即时切换且未提交标题保留。恢复为中文，清空测试草稿，无创建任务或启用计划操作。
- 静态检查解析 1169 个生产文件，无解析错误；中英文各 2321 个词条，静态引用无缺失。候选文本数不是未翻译缺陷数，也不代表全项目已完成本地化。

本轮不包含其他尚未本地化的连接器、技能及复杂任务详情页面，也没有提交或推送代码。
