# 技能页面中英文适配

本轮针对截图中的技能商店与已安装列表，沿用现有 i18next 全局语言状态。

## 实现范围

- CompanySkills 开发与 production 版本：列表、排序、搜索、卡片状态与来源、数量、详情、安装预览、版本和相关弹窗。
- 技能侧栏、系统文件夹名称、文件夹树与项目技能导入弹窗。
- 权限拒绝提示保留分类与权限逻辑，将可翻译的展示元数据交给视图解析。
- 八个已安装的 Paperclip 内置技能摘要提供中英文显示，并纳入搜索。
- 只有来源为 Paperclip、标识在白名单、未派生且摘要与内置英文原文精确匹配时才替换展示摘要。自定义内容、第三方技能和执行用 SKILL.md 不改写。
- 搜索及文件夹路径的缓存依赖包含当前翻译函数，语言切换后重新计算。

## 验证

- 摘要回归测试先确认中文断言失败，再实施修复。
- 8 个相关测试文件、76 个测试通过。
- UI 类型检查与生产构建成功；构建仍有原有配置、CSS 与体积提示。
- 代码差异空白检查通过。
- 浏览器确认八个内置技能的中文摘要、来源标签、数量、排序菜单和新建文件夹弹窗。
- 搜索“邮件”找到 AgentMail；通过组织菜单切换英文，确认列表与摘要恢复英文，再恢复中文。
- 静态扫描无解析错误，中英词典键对齐；扫描结果中的其他模块候选并不代表本轮已完成全项目翻译。

## 边界

技能标识、品牌名、文件路径、用户内容保留原样。SkillStudio 编辑器及其他业务模块仍需独立检查；本轮不声明整个项目完全中文化。未提交或推送代码。
